# E-0055-I01: conservative host MultiMesh experiment

This is Godot presentation infrastructure, not recovered PS2 behavior. TASK0054 native frame packets, source resources, recovered rendering, physics and naming evidence remain unchanged. No original-game equivalence or Verified claim.

## Eligibility and boundaries

The pure host planner accepts only contiguous commands with the same original solid/surface, LOD/visibility, complete material/texture/test/pass state, identity policy and light context. The matrix is the sole differing submission input. Candidates require no light context, flags0x1c0 clear, Copy blend (the port enum for opaque RGB copy), no alpha/deferred environment/320/alpha-rewrite/additive/bias. Source geometry must be nonempty; matrices must be finite affine and have positive determinant. Mirrors and singular/projective transforms remain ordinary draws.

The caller supplies exact view/section/LOD-epoch boundaries. The helper can derive section ownership from original instance_begin/instance_count ranges; missing or ambiguous ownership is marked unknown and ineligible. Groups never skip an intervening command or cross a boundary. Native order and command values are not changed. A one-command eligible span remains an ordinary draw.

`TrackInstancePool` holds separate view/key MultiMesh nodes, references the original Mesh and immutable ShaderMaterial, and uploads owner-local host transforms. It neither converts vertex/custom attributes nor recalculates normals. begin_view advances a per-view generation, end_view hides only unused groups in that view; submit reuses nodes/resources and skips exactly equal transform uploads. Instance capacity grows by powers of two and actual visibility uses visible_instance_count. Changed transforms are uploaded in one MultiMesh.set_buffer call as3x4 row-major transforms (basis rows plus origin), rather than one engine call per instance. The engine helper verifies decoded transforms including nonuniform scale and rotation. Ordinary culling/layer masks remain active. No ignore-culling shortcut, original visibility/LOD modification, or custom shader behavior is introduced. Parent owns runtime selection, material binding, ordering and matching MultiMesh raw-depth proxy integration.

## Track24 bounded numerical investigation

Official Godot4.4.1-stable primary sources: [GLES3 scene shader](https://github.com/godotengine/godot/blob/4.4.1-stable/drivers/gles3/shaders/scene.glsl#L459-L505) and [GLES3 rasterizer](https://github.com/godotengine/godot/blob/4.4.1-stable/drivers/gles3/rasterizer_scene_gles3.cpp#L3227-L3268). The instanced vertex variant multiplies the world matrix by the transposed three supplied transform rows, then constructs view times model. Vertex colour is multiplied by instance colour; when instance colour/custom arrays are disabled, the rasterizer explicitly supplies unit colour and zero custom data. This agrees with the pool transform layout and does not support an unintended default tint explanation. The variant and matrix arithmetic path differ from ordinary meshes; these sources do not guarantee bitwise interpolation equivalence.

Port car_base.gdshader lines121..125 transports native Gouraud values using gs_color_w from projection times MODELVIEW times vertex, then numerator/w reconstruction. Compiler arithmetic, varying interpolation, derivatives/texture sampling and equal-depth primitive behaviour remain possible causes; none is established by the current evidence. Exact encoded depth equality does not prove every interpolated texture or colour input is equal.

Actual mismatch statistics: intermediate-colour differing channel absolute deltas are1:36412,2:8078,3:434,4:1; final deltas1:28170,2:2587. Both signs occur. This is bounded small numerical counterevidence, not authorization to tolerate it. No asset-name exclusion, filtering change or epsilon-based eligibility restriction is justified. The proven safe fallback is not to select MultiMesh: retain it as experimental/off and validate resource/particle reuse independently. Further closure needs an isolated production-shader varying/sampling comparison and exact per-primitive attribution before any new eligibility class can be approved.
