## Confirmed findings

Traverses a circular list identified in the decompile by `piGpffffb538`.
For each pack calls 001AC3F0 with the first argument, or 001AC468 when the
third argument is nonzero. On success unlinks that pack and puts it at the
front of the list; marks returned entry byte +0x78 as 1 and returns it.

After exhausting the pack list, calls 001057D8. If that also returns zero,
returns zero when argument two is zero. Otherwise recursively requests hash
0x19006835 with zero second/third arguments. If still absent calls 00250AB0
and returns zero.

## Limits and port boundary

The native vehicle `Textures` service does not implement this complete routine.
It decodes requested hashes from the original car and shared GLOBAL archives.
Those observed tables have no overlapping hashes; duplicate hashes fail rather
than inventing current residency, list order or resource-manager behavior.
Missing entries fail explicitly; the default-hash branch is not used as a
replacement for missing vehicle assets. See `reverse/structures/vehicle-textures-task0033.md`.
