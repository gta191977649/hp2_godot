# 0x0016A5B0 — menu item lookup by name hash

## TASK-0025 — E-0025-L05

Read-only Ghidra MCP 2026-10-13. Target SLUS_203.62 US PS2, revision unknown, SHA-256
7335b8ed479481082c648958f4b5be4da65b74d042d0ab2f5237df801eafacc2. Original identifier
unknown. No Ghidra edits (AGENT.md R5). No original hardware or PCSX2 comparison, so no
Verified claim. Full write-up: docs/FRONTEND_MENU_LANGUAGE.md.

Walks the circular menu list from its head comparing each item's +0x0C against the requested
name hash; returns the item or 0. The list head is the sentinel, so an empty list returns 0
before any field is read. Port: `MenuList_00169F78::FindByHash_0016A5B0`
(src/game_core/indep/src/fmenus.cpp). The sibling 0016B340 is the same scan over screen groups,
comparing +0x14 instead; the port does not need it because it holds one group per screen.
