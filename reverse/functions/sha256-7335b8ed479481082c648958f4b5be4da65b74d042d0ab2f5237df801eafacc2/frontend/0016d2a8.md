# 0x0016D2A8 — enable/disable and show/hide one menu item

## TASK-0025 — E-0025-L04

Read-only Ghidra MCP 2026-10-13. Target SLUS_203.62 US PS2, revision unknown, SHA-256
7335b8ed479481082c648958f4b5be4da65b74d042d0ab2f5237df801eafacc2. Original identifier
unknown. No Ghidra edits (AGENT.md R5). No original hardware or PCSX2 comparison, so no
Verified claim. Full write-up: docs/FRONTEND_MENU_LANGUAGE.md.

`FUN_0016D2A8(class_name, name_hash, screen, mode)`. Resolves the screen group from the class
name with 0016C8C8, then the menu list with 0016B340, then the item with 0016A5B0. Both lookups
return 0 silently on a miss and the function returns without touching the widget.

- mode 0 or 2: `FUN_00169CB0(item, 1, 0)`, clearing the enabled bit
- otherwise: `FUN_00169BD0(item, 1, 0)`, setting it
- mode 2 additionally: `FUN_00144968(screen, hash, 0)`, hiding the widget
- mode 1 additionally: `FUN_00144968(screen, hash, 1)`, showing it

The only caller recovered so far is the Language Options constructor 001F1A78, with mode 2 on
MENUITEM_7. The original translation unit for this address is not pinned
(docs/ORIGINAL_SOURCE_TREE.md); the port keeps it in fmenus.cpp because it only operates on that
file's menu framework, and is handed the list and screen the caller already owns.
