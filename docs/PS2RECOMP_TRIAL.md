## Hypotheses and unresolved questions

The large envelope likely overstates one function because Ghidra bodies can be
discontiguous. MCP supplies min/max bounds, not address-set ranges; this export
does not repair boundaries or claim continuous ownership. Synthetic callable labels
from the upstream Java exporter were not added; tool may still discover internal targets.
Ghidra names are analysis labels, not asserted original developer identifiers.

Generation does not recover original source, native data structures, hardware
services, or complete runtime behavior. Full generated compilation/link, game boot,
VU/IOP correctness, and original/PCSX2 comparisons were not performed. No recovered
logic was added to game_core, no symbol was promoted to Verified, and no behavior
tests were invented: this task generated unverified instruction translations only.
